Design notes

Visual language: GitHub-dark quality, Linear-level precision. IBM Plex Mono for all code/technical strings; system sans-serif for prose. Left-border colour-coding for message types (blue=user, purple=assistant, green=tool, orange=thinking). All interactive elements have explicit hover/active states and use CSS variables so both dark and light themes work without JS re-rendering.


Session Browser A (cards) vs B (list): Recommend B as the default with A as an optional "card view" toggle. The dense list is significantly more scannable when you have 30+ sessions — you can read project/model/cost/time in one horizontal sweep. The card grid shines for discoverability and when prompt previews need 2 lines, but wastes vertical space at scale. A toggle button between the two views in the toolbar lets each user pick their preference.
